# MusicBoost

קידום ממומן לשירים ופלייליסטים מיוטיוב וספוטיפיי, דרך חשבון המטא של Ignite Records.

## להפעלה אונליין

האתר החי:

**https://40sinfreda.github.io/musicboost/**

מדביקים קישור, בוחרים קהל ותקציב, סוגרים קמפיין. טוקן המטא נשמר בדפדפן בלבד.

## קוד מלא

תיקיית `src` היא האפליקציה המלאה (TanStack Start). האתר החי ב-GitHub Pages רץ מ-`index.html` ו-`app.js`.
